# 세 곳에 남긴다

**검사 질문**: 내 메모리가 지워져도 이 사실이 프로젝트와 사용자에게 남는가? 아니면 아직 저장된 게 아니다.

| 무엇 | 어디 |
|---|---|
| 마인드셋·소통 규칙·반복 실수의 장치 | 플러그인 ugot-mindset(마켓플레이스) → 모든 프로젝트 + 프로젝트 규칙 파일(CLAUDE.md·AGENTS.md) |
| 프로젝트 사실·법칙·실험 결과 | 그 저장소의 문서·장부·코드(커밋) |
| 사용자·조직 지식 | UGOT Space 지식망 |
| 작업 상태·결과 | Work(작업 기록·링크) |
| 개인 메모리 | 위 것들을 가리키는 포인터만 |

교훈이 생긴 **그 턴**에 쓴다. 다음 턴으로 미루면 사라진다. 커밋은 논리 단위마다 바로(몰아서 하지 않는다).
