# 다중 자 법

**왜**: 2026-08 자를 "다음 글자 맞히기"로 바꾸자, 그 자로는 점수가 안 나오는 7월의 최고 후보가 후보 목록에서 조용히 빠져 두 달간 묻혔다. 2026-10-08 밤에도 읽기 자만 돌리고 생성 자를 안 쟀다. 같은 실수(실수 목록 3·4번)의 뿌리는 "한 자"다.

## 규칙

1. **자 목록은 고정, 최소 다섯**: 읽기(공개 벤치 EM/F1, n ≥ 1,000) · 생성(그 계열에 맞는 언어 점수 — 자기회귀면 다음 글자 bpb, 지우고-채우기면 ELBO bpb — 와 표본 품질: distinct-3·반복률·사람 눈) · 구성적 성질(정확 삭제·출처·검증 가능) · 비용(파라미터·학습 시간·추론 시간) · 추세(1×/3×/10× 부호).
2. **후보를 버리는 조건은 둘뿐**: 해당하는 모든 자에서 패배했거나, 구성적 논증(이론)으로 불가능이 보일 때. 한 자에서 졌다고 버리지 않는다.
3. **자가 못 재는 후보 = 자의 결함**: 그 후보를 재는 짝 자를 즉시 추가한다(예: 디퓨전 몸에 ELBO bpb + 표본 품질). "못 재니 제외"는 금지.
4. **자를 바꾸거나 추가하면** 과거 후보 전부를 새 자 집합으로 다시 채점한다(묻힌 승자 복권 검사). 장부에서 효과 크기 상위 3을 다시 뽑는다.
5. **보고는 자별 한 줄씩**(읽기 / 생성 / 성질 / 비용 / 추세). 한 숫자로 "최고"라고 말하지 않는다.
6. **발사 전 체크**: 이 실험은 어느 자들을 내는가? 못 내는 자가 있으면 짝 자를 같이 발사한다(읽기 미세조정과 생성 자 측정을 같은 체인에).
