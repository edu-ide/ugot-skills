

# 제작·납품 양식

필요한 항목만 실제 작업물에 채운다. 짧은 샘플은 하나의 제작 메모나 편집 프로젝트 안에 합쳐도 된다.

## 최소 브리프

| 항목 | 정할 내용 |
| --- | --- |
| 대상·목적 | 무엇을 누구에게 알리는지, 방문/상품 보기/문의/저장 등 주 행동 하나 |
| 사실과 근거 | 상품명·차별점·실제 위치·링크, 가격·행사 조건의 확인 자료와 유효 기간 |
| 자료 | 영상·사진·로고, 파일별 내용·해상도·방향·사용 권리, 추가 촬영 가능 여부 |
| 범위 | 형식·편수·길이·화면비, 기획/촬영/AI/편집/자막/음성 포함 여부 |
| 소통 | 연락 채널, 담당자 한 명, 초안 공유일·피드백 기한·납기·수정 횟수 |
| 게시 | 납품만인지, 게시물 문안·표지·예약/실제 게시까지인지 |

고객 안내 예시: “상품 정보와 촬영본을 보내주시면 핵심 홍보 포인트를 정리해 대본·장면표를 먼저 공유합니다. 확인된 방향으로 초안을 만든 뒤, 시간대를 표시한 피드백을 받아 합의한 수정 범위 안에서 마무리합니다.”

고객 기획이 있으면 그 안에서 개선한다. 기획 포함 상품이라면 빈 콘티를 고객에게 채우게 하지 않는다. 답변이 늦는 경우의 일정 영향과 주말 상담·작업 가능 여부는 실제 합의한 조건을 따른다.

## 휴대폰 촬영 요청

시연형의 시작 세트는 다음 5종류다. 콘티에 필요하지 않은 컷까지 요구하지 않는다.

1. 상품·메뉴 또는 공간의 전체 모습.
2. 만드는 손이나 사용하는 동작. 중요한 동작 전후를 여유 있게 촬영.
3. 재질·내용물·특징의 근접 화면.
4. 완성 결과를 알아보기 쉬운 화면.
5. 상호·상품명·간판·패키지 등 대상을 식별할 화면.

세로 촬영, 원본 파일 전달, 초점·노출 안정, 디지털 줌과 강한 필터 최소화를 제안한다. 손·기계·제품의 컷 연속성을 확인한다. 고객·행인의 얼굴을 쓴다면 촬영·광고 사용 범위를 확인한다. 원본에 들어 있는 상업 음악을 그대로 사용 가능하다고 가정하지 않는다.

## 대본·콘티

| 시간 | 실제 원본/화면 | 화면 자막 | 장면 역할 | 확인할 사실 |
| --- | --- | --- | --- | --- |
| 0~2초 | 매력적인 결과/궁금한 동작 | 한 가지 질문/관심 문구 | 멈춰 볼 이유 | 화면과 문구 일치 |
| 2~7초 | 실제 만들기/사용하기 | 동작이 증명하는 특징 | 구매 이유의 근거 | 동일 제품·실제 특징 |
| 7~12초 | 디테일과 완성 결과 | 기억할 장점 하나 | 질문 해소·보상 | 효과 과장 없는지 |
| 12~17초 | 상품·상호·공간 | 이름과 행동 안내 | 광고 대상·다음 행동 | 실제 이름·링크·위치 |

이는 시연형 17초의 예시다. 다른 형식에는 해당 전개로 교체한다. 음성 포함 시 낭독문과 화면 자막을 별도 열로 두어 모든 말을 과밀하게 반복하지 않게 한다.

가상 카페 예시: 음료 질감 → 커피/우유를 따르는 동작 → 잔 속 변화 → 가상 브랜드와 메뉴명. 보유 원본에 없는 추출·원두 장면은 삭제하거나 기획을 바꾼다. 스톡의 기계·공간을 실제 고객 매장에서 촬영했다고 표현하지 않는다. 샘플의 주문·방문 문구는 가상 광고임을 명확히 하고, 존재하지 않는 링크·주소·가격을 붙이지 않는다.

## 초안과 수정

- 초안에 버전·길이·의도와 고객 확인 핵심 2~3가지를 준다. 예: 특징의 정확성, 상호 표기, 마지막 안내.
- “00:06 자막의 원두명을 ○○로 변경”처럼 시간대·내용을 모아 받는다. 상충 피드백은 고객 책임자의 최종안을 기준으로 한다.
- 오탈자·편집 누락과 새 콘셉트·추가 촬영·편수 확대를 구분한다. 수정 횟수 계산은 합의한 범위를 적용한다.
- 확인된 기획을 기록하되 매번 승인 단계를 늘리지 않는다. 샘플 기획·제작을 일괄 맡겼으면 그 범위의 초안을 먼저 완성한다.

## 납품과 검수

최종 MP4, 선택한 표지·게시물 문안, 원본 프로젝트, 사용 소재 내역 중 계약한 산출물을 제공한다. 프로젝트 소스 제공을 자동 포함하지 않는다.

- 재생·길이·비율·해상도·코덱 검사. `ffprobe` 등 실제 사용 가능한 도구를 활용한다.
- 전체 재생 또는 타임라인 검토로 순서·검은 프레임·전환·정지 프레임 과다를 확인한다.
- 한글·숫자·브랜드·CTA가 읽히고 앱 UI나 세로 크롭에 가려지지 않는지 확인한다.
- 제품·메뉴·공간의 연속성과 화면·주장의 일치를 확인한다.
- 음성/음악 포함 시 실제 청취·볼륨·클리핑·싱크·권리 검사. 무음 요청이면 불필요한 오디오를 추가하지 않는다.
- 가상 브랜드/스톡/AI 등 시연 성격을 오해하지 않게 표시한다.

렌더 완료, 기술 검사, 시각 검수, 고객 확인, 실제 게시 상태를 혼동하지 않는다. 메타데이터나 표본 프레임만 확인했다면 그 범위를 그대로 보고한다.

## 반복 제작과 업로드 계획

정기 제작에서는 확인된 상품 사실과 촬영본을 재사용하면서 **구매 이유·도입·증거 장면**을 바꾼다. 주제 예시는 대표 제품 시연, 자주 묻는 질문, 선택·비교, 공간/사람 이야기다. 모든 고객에게 이 주제나 업로드 횟수를 강제하지 않는다.

계약 편수·촬영량에 맞춰 각 게시물의 목적·형식·필요 원본·초안일·피드백일·게시 예정일·상태를 정한다. 게시까지 맡았다면 고객 소유 계정의 필요한 초대 권한을 사용한다. 영상·문안·표지·링크·시간·대상 계정이 승인 범위인지 확인해 실행하고 게시 URL/예약 상태를 다시 읽는다. 권한 수락을 광고비 지출이나 무제한 게시 승인으로 해석하지 않는다. 납품 계약이면 파일과 문안을 인계한다.

성과 확인 권한과 요청이 있으면 같은 기간으로 도달·재생·평균 시청/유지·저장·프로필 방문·링크 클릭·측정 가능한 문의를 비교한다. 현재 계정에서 제공하지 않는 지표를 만들지 않는다. 조회수를 매출 증명으로 쓰지 않고 작은 표본의 우열을 확정하지 않는다. 다음 묶음은 어떤 변경이 반응에 영향을 줬는지 설명할 수 있게 설계한다.

## 샘플 적용 예 — 가상 카페

18초 가상 카페 **오후의 잔 / 아이스 라테** 메뉴 광고. 일반적인 취향 투표 샘플과 별개의 새 촬영본을 고른 예다. 실제 제조 과정을 보여 주는 릴스와 짧은 제품 디테일 영상의 간결한 구성을 참고한다. 음성은 넣지 않았다.

- 소재: [aidin gheshlaghi의 아이스라테 제조 영상](https://www.pexels.com/video/a-person-preparing-a-glass-of-iced-latte-16612964/), 약 44.16초·1920×1080 원본.
- 사용 조건: [Pexels 라이선스](https://www.pexels.com/license/)를 작업 시점에 확인. 다른 용도로 재사용할 때는 필요한 권리와 조건을 다시 확인한다.
- 제작안: 동일 컵·장소의 커피 → 우유 → 완성 흐름, 세로 크롭·근접 컷·속도 변화·한글 자막·가상 상호와 CTA. 영상 전체에 “가상 카페 · 제작 샘플”을 표시한다.
- 교훈: 이 샘플은 기술 검수를 통과했지만 참고 릴스와 느낌이 다르다는 피드백을 받았다. 주요 장면만 보고 자막·전개의 리듬과 출연자의 반응을 충분히 분석하지 않았고, 제품을 붓는 장면과 설명 자막으로 축소했기 때문이다. 기술 검수 통과를 레퍼런스 스타일 재현의 근거로 쓰지 않는다.
