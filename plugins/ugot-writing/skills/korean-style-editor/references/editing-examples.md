# 문맥에 따른 한국어 교정 사례

다음은 이 스킬을 위해 만든 설명용 예문이다. 사용자의 실제 글이나 교정 효과를 입증한 실험 자료가 아니다. 문장을 그대로 외워 다른 글에 적용하지 말고, 수정한 이유와 유지한 조건을 참고한다.

| 상황 | 원문 | 교정 예 | 판단 기준 |
| --- | --- | --- | --- |
| 과장된 대조 | 이 도구는 단순한 검색기가 아니라 검색 시간을 줄여 주는 도구입니다. | 이 도구는 검색 시간을 줄여 줍니다. | 검색기라는 성격을 부정할 근거가 없다. 기능을 직접 설명한다. |
| 필요한 대조 | 신청 마감일은 10월 3일이 아니라 10월 5일입니다. | 신청 마감일은 10월 3일이 아니라 10월 5일입니다. | 잘못 알려진 날짜를 바로잡는 대조와 두 날짜를 유지한다. |
| 근거 없는 비유 | 이 설정은 화면 전체를 조용히 떠받칩니다. | 이 설정은 화면 전체에 적용됩니다. | 앞뒤 문맥에서 실제 적용 범위를 확인한 경우에만 이렇게 고친다. 범위를 모르면 이 수정도 하지 않는다. |
| 문자 그대로의 의미 | 도서관에서는 조용히 이야기해 주세요. | 도서관에서는 조용히 이야기해 주세요. | 조용히가 실제 소리 크기를 뜻한다. |
| 불필요한 명사화 | 담당자에 의해 설정에 대한 변경이 수행되었습니다. | 담당자가 설정을 변경했습니다. | 원문에 있는 행위자와 완료 시점을 유지한다. |
| 주체를 모르는 피동 | 설정이 변경되었습니다. | 설정이 변경되었습니다. | 원문에 없는 담당자나 시스템을 주체로 넣지 않는다. |
| 확신을 유지 | 이 방법으로 오류가 줄어들 수 있습니다. | 이 방법을 쓰면 오류가 줄어들 수 있습니다. | 가능성을 확정 효과로 바꾸지 않는다. |
| 나열을 인과로 바꾸지 않기 | 서버를 재시작했습니다. 이후 오류가 줄었습니다. | 서버를 재시작한 뒤 오류가 줄었습니다. | 시간 순서만 알려져 있다. “재시작해서 해결됐다”라는 원인을 만들어내지 않는다. |
| 숫자와 조건 | 지난달 신청은 120건이었고, 그중 30건은 아직 처리되지 않았습니다. | 지난달 신청 120건 중 30건은 아직 처리되지 않았습니다. | 총계·부분집합·미처리 상태를 함께 유지한다. |
| 같은 숫자, 다른 뜻 | 오류율은 2%, 재시도율은 5%입니다. | 오류율은 2%이고 재시도율은 5%입니다. | 숫자 검사만으로는 두 수치가 뒤바뀐 결과를 찾지 못한다. 대상까지 확인한다. |
| 인용 보존 | 담당자는 “10월 5일까지 보내 주세요”라고 말했습니다. | 담당자는 “10월 5일까지 보내 주세요”라고 말했습니다. | 인용을 “제출해 주세요”로 고치지 않는다. |
| 불필요한 요약 | 접수는 금요일에 마감됩니다. 요약하면, 금요일까지 접수해야 합니다. | 접수는 금요일에 마감됩니다. | 마지막 문장이 새 정보를 더하지 않는다. |
| 의미 있는 다음 행동 | 접수는 금요일에 마감됩니다. 제출 전에 서명이 빠졌는지 확인해 주세요. | 접수는 금요일에 마감됩니다. 제출 전에 서명이 빠졌는지 확인해 주세요. | 다음 행동을 안내하는 문장은 남긴다. |
| 실제 세 가지 절차 | 신청서를 작성하고, 담당자에게 보내고, 접수 확인을 받아 주세요. | 신청서를 작성하고 담당자에게 보낸 뒤 접수 확인을 받아 주세요. | 세 단계가 필요하다. 목록 여부는 분량과 읽기 편의로 정한다. |
| 사용자 말투 | 직접 써 보니 생각보다 편했다. 다음에도 이 방법을 쓸 것 같다. | 직접 써 보니 생각보다 편했다. 다음에도 이 방법을 쓸 것 같다. | 이미 자연스럽다. “혁신적인 경험을 선사했다” 같은 감상을 추가하지 않는다. |

## 직접 확인해야 하는 의미 변화

자동 보호 항목이 같아도 아래 수정은 의미가 달라진다.

- “오류율은 2%, 재시도율은 5%” → “오류율은 5%, 재시도율은 2%”: 숫자와 단위가 같아도 대상이 바뀌었다.
- “모든 요청이 실패한 것은 아니다” → “모든 요청이 실패했다”: 부정과 범위가 바뀌었다.
- “도입하면 비용이 줄어들 수 있다” → “도입해서 비용이 줄었다”: 가능성과 계획이 확정 결과로 바뀌었다.
- “서울에서 부산으로 보냈다” → “부산에서 서울로 보냈다”: 고유명사가 같아도 방향이 반대다.

원문에서 그 변화의 근거를 찾을 수 없으면 원래 뜻을 복원한다. 필요한 대조·피동·조건 표현은 자연스럽다는 이유로 지우지 않는다.
