# 베스트셀러 지향 상품·원고 검토

## 목적과 권한

독자가 구매 전에 기대한 경험을 실제 책이 제공하는지 검증한다. 베스트셀러는 결과이지 문장 공식이나 임의 점수로 증명할 수 있는 속성이 아니다.

- 먼저 이 스킬을 쓰는 이유와 검토 범위를 사용자에게 알린다.
- 검토 요청은 원고 변경·가격 적용·후기 수집 메시지 발송·출시 권한이 아니다. 원본은 보존하고 별도 검토 보고서만 만든다.
- 제작 요청이면 검토 결과를 제작에 반영하되, 전체 확대 전에 실제 출력한 대표 페이지를 확인한다.
- `references/research-and-rubric.md`를 전부 읽고 근거와 자체 편집 기준을 구분한다.

## 1. 독자와 구매 약속부터 정의

다음 문장을 실제 상세페이지와 원고에서 채운다.

> [어떤 상황의 독자]가 [왜 지금] 이 책을 골라, 읽은 뒤 [무엇을 이해하거나 경험]하게 되는가?

장르에 맞게 판단한다. 소설·그림책에 체크리스트나 조언을 강요하지 않는다. 사주 해설의 독자 경험도 수익·건강·미래 사건의 예측 성능과 구분한다. 가격은 제안가인지 실제 결제 가격인지 명시한다.

## 2. 근거 수집

1. 실제 전달할 파일의 경로·버전·해시·쪽수, 상세페이지와 목차를 확인한다. 파일명이나 manifest만으로 본문 완성을 인정하지 않는다.
2. 가능하면 전체 텍스트를 추출한다. 표지, 본문, 공통 부록, 워크시트, 고지의 쪽수를 나누되 분류 기준을 적는다.
3. 다상품이면 공통 틀과 공통 내용을 별도로 검사한다. 정확히 일치하는 본문과 단지 비슷한 주제를 구분한다. 제목·페이지 번호를 제외할 때도 연도·점수·원문 근거는 보존한다. 분모와 제외 규칙을 공개한다.
4. 원본 PDF에서 실제로 렌더된 페이지를 본다. 시각 점검 범위와 미점검 범위를 적는다. 대표 페이지만 보고 전권 디자인 통과를 선언하지 않는다.
5. 시장·가격·베스트셀러 여부를 판단한다면 현재 채널의 비교 상품과 날짜를 웹으로 확인한다. 독자 기대를 설명하는 판매 문구와 실제 판매량 증거는 다르다. 근거가 없으면 수요·전환율·최적 가격은 미검증이다.

## 3. 약속 → 제공 페이지 → 독자 가치 표

상세페이지의 핵심 약속마다 `약속 / 실제 페이지 / 새롭게 알게 되는 것 / 근거 / 판정`을 작성한다.

- 페이지가 존재하는 것과 약속을 충분히 충족하는 것은 다르다.
- 제목을 다른 상품명으로 바꿔도 내용이 그대로 성립하는지 확인한다. 공통 기초 지식은 허용하지만 전문 상품의 핵심 가치를 대신하게 하지 않는다.
- 순서대로 읽을 때 각 페이지가 새 질문에 답하는지 확인한다. 같은 조언을 이미지와 문장만 바꿔 늘리지 않는다.
- 원리와 일상 예시를 연결하되, 입력받지 않은 직업·재정·가족 경험을 개인의 사실로 단정하지 않는다.

## 4. 읽기 경험과 이미지

- 짧은 해석형 리포트는 `특징 → 변화 이유 → 나에게 맞는 한 줄 조언`을 기본 단위로 삼되, 각각 새 정보를 맡긴다.
- 해설, 계산 원문, 주의 고지를 정확히 이름 붙인다. 해설을 복사해 ‘원문 근거’에 놓지 않는다.
- 그래프의 범위·단위·산식 버전·이전 대비 차이와 해설의 연결을 확인한다. 방향 화살표가 불확실한 지수를 실제 재산 손실처럼 보이게 하지 않는지 점검한다.
- 이미지가 무엇을 설명하는지 한 문장으로 적는다. 원인, 대조, 단계, 현재 위치를 보여주는 자산을 우선한다. 장식만 늘리거나 무관한 아이콘을 재사용하지 않는다.
- 제작이 승인된 경우 필요한 자산이 없으면 적합한 자산을 새로 만든다. 참조 이미지의 전체 구성과 그룹 컨테이너, 정비율, 투명 외곽, 레이어 위계, 텍스트 영역을 확인한다. 이미지 생성·편집에는 해당 도구와 스킬을 따른다.
- 큰 여백을 억지로 글이나 일러스트로 채우지 않는다. 이해에 필요한 내용을 키우거나 두 페이지를 합쳐도 되는지 먼저 판단한다.
- 모바일에서 제목·핵심 해설을 읽을 수 있는지 확인한다. 확대 조작 가능성과 기본 크기 가독성은 별도 판정한다.

## 5. 판정과 개선 순서

수치형 ‘베스트셀러 점수’ 대신 `충족 / 부분 충족 / 미충족 / 미검증`과 페이지 증거를 제시한다.

우선순위는 다음과 같다.

1. 허위 약속, 개인정보, 누락, 잘못된 계산, 미연결 개인화 등 신뢰·전달 문제.
2. 이 책만의 구매 이유, 내용 깊이, 상품 간 중복, 반복 조언.
3. 목차 순서, 정보 위계, 가독성, 이미지 의미와 디테일.
4. 상세페이지 표현, 실험할 가격·제목·판매 동선.

치명적인 미충족을 표지의 미감이나 많은 쪽수로 상쇄하지 않는다. 편집 완성도, 출력 완성도, 운영 준비, 시장 반응을 각각 판정한다.

## 6. 다음 검증

베타 독자 검토를 제안할 때는 ‘좋나요?’ 대신 다음을 묻는다.

- 보기 전에 예상한 내용과 실제로 받은 내용은 어떻게 다른가?
- 읽은 뒤 남은 새로운 이해 한 가지는 무엇인가? 어느 페이지인가?
- 자기 상황과 맞지 않거나 반복되어 넘긴 부분은 어디인가?
- 원문을 건너뛰고 해설만 읽어도 핵심을 설명할 수 있는가?

소수 독자 검토는 방향 수정용 정성 근거일 뿐 판매 가능성의 통계 검증이 아니다. 실제 전환율은 방문·미리보기·구매·환불의 기간과 분모를 함께 확보했을 때만 보고한다. 자동 연락이나 유료 실험은 별도 승인 없이 실행하지 않는다.

## 산출물

결론 → 강점과 근거 → 큰 결함과 페이지 → 우선 수정안 → 검증 범위·남은 불확실성 순서로 간결하게 전달한다. 웹 출처는 해당 주장 가까이에 링크한다. 검토를 통해 이전 추천이 달라지면 달라진 이유를 숨기지 않는다.
