# 릴스 광고 제작

영상의 재미가 실제 상품·매장과 연결되고, 시청자가 다음에 무엇을 할지 알 수 있는 릴스를 만든다. 형식에 맞는 촬영과 편집을 선택하며, 기획서만으로 영상 제작을 완료했다고 보고하지 않는다.

## 시작과 형식 선택

1. 현재 요청이 레퍼런스 조사, 첫 샘플, 고객 납품, 정기 제작 중 무엇인지 확인하고 이미 정한 브랜드·형식·음성·납기·예산을 이어받는다. 기존 산출물과 사용 가능한 원본을 먼저 확인한다.
2. 광고 대상, 핵심 고객, 근거가 있는 구매·방문 이유 하나, 마지막 행동 하나를 정한다. 가상 브랜드 포트폴리오는 영상과 납품 설명에서 가상 샘플로 구별한다. 실제 상호·가격·재고·위치·후기·성과를 만들어 넣지 않는다.
3. [형식별 설계](references/formats.md)에서 목적과 사용자가 지정한 레퍼런스에 맞는 형식을 고른다. 필요한 출연·행동·반응이 현재 원본에 있는지 확인한다. 원본 확보가 쉽다는 이유로 출연·이야기 중심 요청을 제품 디테일 영상으로 바꾸지 않는다. 지정한 방식이 없다면 확보 가능한 원본으로 시연·제품 디테일·공간형을 선택할 수 있다.
4. 실사 자료로 구현할 수 있는 요청을 임의로 AI 영상이나 슬라이드쇼로 바꾸지 않는다. AI·직접 촬영·고객 촬영·스톡을 선택한 이유와 실사 대체 여부를 분명히 한다. 유료 생성은 이미 승인된 비용 범위에서 진행한다.

“모든 릴스”는 여러 제작 형식을 지원하라는 요청으로 해석한다. 이 스킬의 근거는 **2026-09-09에 분석한 공개 릴스 10편, 총 392.917초**이다. 전체 길이에 걸친 0.5초 간격 786개 표본, 첫·끝·주요 전환 보강 화면, 자동 음성 전사와 자막 대조로 이전의 드문 표본 분석을 보완했다. 모든 프레임의 연속 시청, 직접 음성 청취, 크리에이터의 모든 영상, 성과 검증을 뜻하지 않는다. [10편 관찰 기록](references/observed-reels.md)을 읽어 형식별 차이와 확인 범위를 따른다. 영상별 관찰 사실과 자체 제작 제안을 섞지 않는다.

## 레퍼런스의 느낌을 제작 기준으로 바꾸기

- 한 편을 주 기준으로 정하고, 다른 영상은 자막이나 구도처럼 적용할 요소가 분명할 때만 보조로 사용한다. 서로 다른 형식의 공통점만 추려서 사용자가 원한 느낌을 희석하지 않는다.
- 주 기준은 도입부터 결말까지 흐름을 확인한다. 장면·자막이 바뀌는 시각, 구도와 카메라 움직임, 말투·반응, 시청자가 기다릴 결과, 상품이 등장하는 순간과 엔딩을 기록한다. 재생 버튼을 누르고 몇 장면을 캡처한 것만으로 전체 흐름을 분석했다고 보고하지 않는다. 확인할 수 없는 구간·소리는 미확인으로 남긴다.
- `원본에서 관찰한 요소 → 새 콘티에서 대응하는 장면 → 필요한 촬영본`을 연결한다. 직원의 개인 반응, 반복 선택, 반전 등이 재미의 핵심이면 단순한 제품 클로즈업이나 일반적인 설명 자막으로 대체하지 않는다.
- 음성 제작을 미뤄도 이야기와 자막의 말투·타이밍은 설계한다. 소리를 추가하면 전개가 약한 문제가 해결될 것이라고 가정하지 않는다. 원본의 소리를 듣지 않았다면 그 말투나 음악 박자를 분석했다고 쓰지 않는다.
- 브랜드 상시 표시, 큰 제목, 정형화된 프로필 안내 카드를 모든 형식에 붙이지 않는다. 주 기준에서 광고 정보가 드러나는 방식과 시점을 확인해 목적에 맞게 정한다.
- 컷 수와 정보 변화 수를 따로 센다. 같은 구도의 선택 게임은 후보·승자·표정이 바뀌며 진행된다. 느린 시연도 원두·조작·추출·세척처럼 새 구매 정보를 계속 보여 줄 수 있다. 빠른 컷이나 큰 자막을 보편 해답으로 만들지 않는다.
- 구간마다 `새로 알게 되는 사실 / 기다리는 결과 / 등장인물의 반응` 중 무엇이 추가되는지 적는다. 모두 없고 제품 이름과 보이는 동작만 반복되면 원본을 확보하거나 콘티를 바꾼다. 음성만 추가하는 수정으로 끝내지 않는다.
- 영상 분석은 출처 URL, 파일 길이·스트림, 전체 디코드 결과, 추출 간격, 실제 확인한 표본과 미확인 항목을 기록한다. 일정 간격 추출은 첫 0.2초나 짧은 효과를 놓칠 수 있으므로 첫 프레임·실제 마지막 프레임·핵심 전환을 별도로 확인한다. 자동 전사의 문장 경계를 컷 또는 자막 경계로 바꾸어 보고하지 않는다.

## 제작에 필요한 자료와 소통

- [제작·납품 양식](references/production-workflow.md)을 사용해 브리프, 촬영 요청, 대본·콘티, 수정 범위와 납품물을 만든다. 고객에게 완성된 기획을 반드시 받아야 한다고 가정하지 않는다. 고객은 상품 사실과 자료를 제공하고, 계약에 포함된 기획·대본·콘티는 우리가 제안한다.
- 보통 **자료 확인 → 기획·콘티 공유 → 초안 → 합의한 수정 → 최종 검수·납품**으로 진행한다. 이미 승인된 단계는 반복 승인받지 않는다. 샘플 제작을 요청받았으면 가정이 명확한 가상 예시를 바로 제작할 수 있다.
- 미정 사실은 그 사실이 필요한 장면에만 영향을 주게 한다. 실제 가격·혜택이 없으면 사용 장면과 상품 특징으로 기획한다. 납품·견적 범위를 초과하는 촬영, 새 기획, 추가 편수는 구분한다.

## 영상으로 구현하기

- 소재의 실제 파일·길이·구도·권리 근거를 확인한 뒤 컷을 잡는다. 사용자가 참고 원본 분석을 요청했다면 플랫폼 약관이 허용하는 방법으로 공개 원본을 확인해 분석한다. 분석용 확인과 고객 광고에 원본·음악·인물을 재사용하는 권리는 구별한다. 참고 릴스를 볼 수 있다는 사실을 재편집·상업 사용 허가로 해석하지 않는다.
- 세로 9:16을 기본 작업안으로 삼되 실제 납품 규격을 따른다. 중요한 자막·상품·상호는 앱 UI에 가리지 않는 중앙부에 두고 현재 미리보기에서 확인한다. 고정된 안전 영역 숫자를 모든 기기·지면의 규칙이라고 설명하지 않는다.
- 자막은 한 번에 한 의미, 보통 1~2줄로 구성한다. 화면이 이미 보여 주는 동작을 반복하기보다 구매 이유·질문·전환점을 보완한다. 강한 첫 장면 뒤에도 주장을 뒷받침하는 제품·공간 장면이 이어지게 한다.
- 컷 길이와 총길이는 형식에 따라 정한다. 첫 시연 샘플의 15~20초는 출발점이며 모든 릴스의 최적 길이나 성과 보장이 아니다. 속도만 높여 이해 시간이나 완성 결과를 없애지 않는다.
- 음성은 선택 항목이다. 사용자가 음성 작업을 미루면 음성 없이 제작한다. 요청되면 직접 녹음, 상업 사용 가능한 TTS, 동의된 음성 등 실제 사용 범위를 확인한다. 유명 목소리 복제를 기본 제작 단계에 넣지 않는다.
- 사용 가능한 편집·렌더 도구로 실제 파일을 만든다. 기존 프로젝트를 보존하고 버전을 구분한다. 무거운 렌더는 시간·CPU·메모리 한도를 두고 상태를 확인하며 실행한다.

## 검수와 완료 보고

메타데이터 검사와 화면 검사를 둘 다 수행한다. 전체 재생 또는 타임라인 검토로 컷 연결을 확인하고, 첫 프레임·전환 지점·중간·마지막의 자막/상품/CTA를 시각적으로 검수한다. 길이·해상도·코덱·프레임·오디오 트랙, 한글 글리프·잘림·색 대비, 영상 끝의 여유와 반복 연결을 확인한다. 실제 하지 않은 시청·음성 청취는 완료라고 쓰지 않는다.

기술 검수와 레퍼런스 반영 검수는 별도로 기록한다. 주 기준과 샘플의 도입·전개·반응·자막 리듬·상품 연결을 대조해 유지한 요소와 빠진 요소를 적는다. 파일이 재생되고 자막이 읽힌다는 사실이나 스킬 형식 검사 통과를 사용자가 원하는 스타일의 재현 근거로 쓰지 않는다. 스타일 불일치 피드백을 받은 샘플은 검증된 제작 사례로 재사용하지 않는다.

최종 응답에는 재생 가능한 로컬 영상, 핵심 제작 의도, 적용한 레퍼런스 원리, 검증한 범위와 남은 한계를 간결히 담는다. 가상 브랜드·스톡 기반 샘플을 실제 고객 매장 촬영이나 고객 실적으로 소개하지 않는다.

정기 제작을 요청받으면 [반복 제작과 업로드 계획](references/production-workflow.md#반복-제작과-업로드-계획)을 따른다. 제작 완료, 업로드 초안, 예약 설정, 실제 게시를 구분한다. 제작 요청만으로 계정 게시·댓글·DM·광고 집행을 추가하지 않는다. 해당 실행이 이미 승인되어 있으면 같은 범위에서 진행한다.

## 다른 사업 작업과 연결

릴스 제작·정기 콘텐츠 운영과 Google Ads/YouTube 유료 광고 대행은 별도 범위다. 유료 집행이 포함되면 광고 운영 스킬이 있으면 함께 쓴다. 기본은 고객 소유 계정의 필요한 작업 권한을 초대받고 매체비는 고객이 직접 결제하는 구조다. 비밀번호·인증번호를 요구하거나 작업 권한을 광고비 지출 승인으로 해석하지 않는다. 새 계정 권한과 플랫폼 규칙은 실행 시점의 공식 안내를 확인한다.
