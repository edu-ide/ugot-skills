

# 형식별 설계

사용자가 정한 주 레퍼런스의 형식과 구매 이유를 먼저 확인하고 필요한 촬영본을 대조한다. 지정 형식이 없을 때 확보 가능한 장면을 기준으로 선택한다. 아래 구조는 자체 제작 가설이며 동일 문구·컷 수·길이를 복제하는 규칙이 아니다. 모든 원본에 구매 CTA가 있지는 않다. 새로운 형식도 `도입 → 전개 → 상품 연결 → 종료 방식`과 실제 촬영 조건으로 추가할 수 있다.

| 형식 | 도입 → 전개 → 상품 연결 → 종료 | 필요한 원본 | 적용 판단과 흔한 실패 |
| --- | --- | --- | --- |
| 직원의 추천·경험담 | 화자와 추천 메뉴 → 추천 계기·비교 → 취향별 선택·주문 방법 → 시음·반응 | 직원 출연, 실제 경험과 상품 사실, 제조, 시음·반응 | 매샷추 참고. 제조 장면은 배경이고 화자의 경험이 전개를 만든다. 제품 스톡에 동작 설명만 붙이는 방식으로 대체하지 않는다. |
| 생활 속 제품 시연 | 생활 맥락/제품 예고 → 단계별 사용 → 완성 결과 → 관리 편의·마무리 | 전체, 손의 동작, 기능 디테일, 결과, 관리 과정 | 바리스티나 참고. 느린 구도에서도 새로운 정보를 쌓는다. 마지막 검색 카드는 원본의 필수 구성 요소가 아니다. |
| 반전·궁금증 | 결말을 기다리게 하는 상황 → 긴장 유지 → 실제 상품/매장으로 의외의 전환 → 상호·검색 | 직접 만든/사용 허가된 도입, 연결 동작, 선명한 상품·상호 | 상호가 지나가 버리지 않도록 인지 시간을 확보한다. 원본 소재를 확보하기 어렵다면 다른 형식 선택. 고집돌우럭·선희네쌈밥집 참고. |
| 선택 게임·월드컵 | 바로 두 후보 제시 → 승자 유지·새 후보·망설임 → 홍보 상품이 후보로 등장 → 선택 결과 회수·참여 안내 | 출연자의 실제 선택·반응, 비교 상품, 표지·이름, 홍보 상품 실물 | 긍정필터 도서 홍보 참고. 한 번의 A/B 투표 카드로 축소하지 않는다. 고정 상단 제목은 게임 규칙이며 브랜드 상시 표기와 역할이 다르다. |
| 브랜드·공간 이야기 | 공간/사람의 맥락 → 이용 이유·작은 이야기 → 상호와 경험 연결 → 로고·여운 | 안정된 공간 전체, 특징, 허가 범위의 사람/동선, 상호 | 한 장면과 자막만으로도 가능하나 분위기만 보여 주고 대상·특징을 놓치지 않는다. 인천공항 참고. 방문 안내 추가는 자체 기획이며 원본에서 관찰한 필수 구성이 아니다. |
| 사용 리뷰·문제 해결 | 구체적 고민 → 실제 사용 → 관찰 가능한 결과·특징 → 확인·구매 | 사용 전 상황, 동일 제품의 사용, 확인 가능한 결과, 패키지 | 허구의 후기나 촬영하지 않은 효과를 쓰지 않는다. 샴푸 사례의 과정 연결은 참고하되 주장 자체를 옮기지 않는다. |
| 언박싱·제품 디테일 | 제품/가치 질문 → 개봉·재질·기능 → 손으로 보여 준 사용 이점 → 상품명·구매처 | 패키지, 외관, 기능 동작, 실제 사용, 모델명 | 이름만 나열하기보다 체감할 차이를 고른다. 17초 키보드의 간결함과 COX 기능 시연 참고. |
| 출연·상황극 | 갈등/선택/의외의 캐릭터 → 대사 속 상품 특징 → 발표 기대와 반전 → 행사 안내 | 출연자, 대본, 역할/의상·공간, 제품, 리액션 | 올리브영은 상품 혜택을 후보의 수상 소감에 담고, 선택을 못 하는 반전으로 마무리한다. 단순히 우승 제품 하나를 발표하는 틀로 오독하지 않는다. 연기·재촬영 비용을 포함한다. |

## 촬영본에서 고르는 기준

- 손으로 만드는 장면과 완성 결과가 있다: 시연형. 원본들이 실제 같은 제품인지 확인한다.
- 제품 외관·작동만 있다: 디테일형. 없는 효과를 합성된 전후 비교로 채우지 않는다.
- 공간만 있다: 공간형. 이용 맥락·실제 특징·상호를 붙일 수 있는지 확인한다.
- 사장님/직원 출연이 가능하다: 선택 게임·설명형·상황극. 쉬운 고정 구도부터 제안할 수 있다.
- 권리를 확보한 도입 소재와 상품 연결 장면이 있다: 반전형. 단지 인기 영상이라는 이유로 선택하지 않는다.
- 고객 자료 없이 샘플을 요청했다: 사용 가능한 스톡/직접 제작 자료에 맞는 가상 브랜드. 서로 다른 기계·공간을 한 실제 매장의 증거처럼 소개하지 않는다.

## 광고 연결 점검

1. 자막을 지워도 광고 대상이 화면에 나타나는가?
2. 도입의 질문이나 상황이 상품 장면에서 해소되는가?
3. 장점의 근거가 촬영본이나 확인된 상품 자료에 있는가?
4. 상품·상호를 알아볼 시간이 있는가? 행동 요청이 있는 경우 그것을 읽을 시간도 있는가?
5. 브랜드 인지·시연·참여 중 목표에 맞는 종료인가? 문의·구매가 목표인 경우 필요한 다음 행동을 추가할 수 있는가?

이 질문들이 기획을 바꾸지 않는다면 같은 체크를 반복하지 말고 제작으로 진행한다.
