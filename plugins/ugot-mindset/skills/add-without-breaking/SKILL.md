# add-without-breaking — 더하되 깨지 않기

**원칙**: 추가는 항상 기존 것과 **같은 시험대**에서 확인한다. 순차 땜질이 진동하는 이유는 시험대가 매번 다르기 때문이다(예: 능력을 하나씩 순차로 더하자 유창성과 대화 턴 능력이 번갈아 무너졌다).

- 모델: 기존 가중치 동결 + 제로-초기화 성장 + 기존 전부 재측정(23/23).
- 소프트웨어: 기능 하나 넣고 전체 테스트, 스냅샷 비교.
- 규칙·스킬: 새 게이트가 기존 게이트와 충돌하지 않는지(Stop 훅 병렬 실행 같은 상호작용) 같이 돌려 본다.
- **길목**: 지킬 성질은 길목의 실행 검사로 둔다. 막히면 고치거나 선언한다. 우회 금지, 되돌릴 수 없는 일은 선언으로 못 지나간다.
