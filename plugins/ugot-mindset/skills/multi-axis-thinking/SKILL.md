# 다차원 사고

**탄생 (2026-10-08 21:40 KST)**: 하루 종일 한 축으로만 움직였다. 숫자가 오면 숫자에, 원리가 떠오르면 원리에, 사용자가 다른 축을 꺼내면 그제야 그 축으로. 사용자: "일차원적인 거 같아." 결과론·원리론·목표론은 서로 다른 축이지 선택지가 아니다.

## 일곱 축 (판단 전에 한 줄씩, 빠지면 "모름"이라고 쓴다)

1. **목표** — 이 결정이 고정된 상위 목표에 복무하는가, 수단만 바꾸는가.
2. **원리(기구)** — 왜 그렇게 되는가의 메커니즘. "숫자가 그래서"는 원리가 아니다.
3. **증거** — 숫자가 말하는 것과 **못 말하는 것**(표본·seed·자·섭동).
4. **선행** — 분야가 이미 아는 것(검색했나, 기억인가).
5. **대안 설명** — 같은 관측을 설명하는 다른 가설 2개(레시피·자·구현 결함).
6. **반증** — 내 결론이 틀렸다면 무엇이 보일까, 그걸 어떻게 재나.
7. **비용·시간** — 되돌릴 수 있나, 얼마나 걸리나, 지금 꼭 해야 하나.

## 규칙

- **결정 = 축 3개 이상이 같은 방향**일 때만. 하나로 결정하면 그것이 일차원이다.
- 축끼리 **충돌하면 충돌을 적는다**("증거는 바꾸라 하고 원리는 유지하라 한다") — 충돌을 숨기고 한쪽을 고르지 않는다.
- 결과를 읽는 순간이 가장 위험하다: 숫자를 보면 먼저 2·5·6을 쓴 뒤에만 행동한다.
- 짧게: 일곱 줄이면 충분하다. 사용자에게는 결론과 충돌한 축만 말한다(visual-first 글 칸).

## 예 (오늘)

(가상 예) 새 답안 생성 방식이 1000 step에서 정확도 0 → 일차원: "방식 교체". 다차원: 목표(문서에서 답을 찾는 과제라 답 위치를 가리키는 편이 원리에 맞음) · 원리(글자를 새로 만드는 방식은 결정할 것이 많고, 가리키는 방식은 적음) · 증거(1000 step·작은 배치라 표본 부족으로도 설명 가능) · 선행(예전 실험에서 가리키는 방식이 더 나았음) · 대안(미세조정 부족/디코딩 순서 문제) · 반증(가리키는 방식도 0이면 읽기 자체가 병) · 비용(30분) → 셋 이상이 "가리키는 방식"을 가리키되, 대안 축이 남으니 생성 방식은 폐기가 아니라 보류로 기록.

## 발사 전 설계 카드 의무 (2026-10-09 추가, user "다중 차원으로 최적의 설계를 한 다음 작업해야 되는 거 아니야? 왜 자꾸 다중 차원으로 생각을 안 하는 거임")

학습·사전학습·몸 발사는 **설계 카드가 있어야** 한다(launch-gate 훅이 DESIGN=<카드> 없는 발사를 막는다). 카드 = 일곱 축 표(목표·원리·증거·선행·대안·반증·비용) + 다섯 자 사전 등록(읽기·생성·구성적 성질·비용·추세) + 판정 규칙 + 실행 순서 + 빈 "판정" 절. 대안은 최소 셋, 반증 조건은 숫자로. 연기 시험·평가만·재개는 예외.

## 8번째 축 — 통념 밖 선언 (2026-10-10 추가, user "모든 수준에서 상식·이미 연구된 수준으로 해결하지 말라고 했는데 왜 자꾸 어기냐")

일곱 축이 다 차 있어도 설계가 **이미 연구된 부품의 재조립**이면 카드는 무효다(2026-10-08 지시 뒤 48시간 안에 낸 세 설계가 전부 기존 방법의 재조립이었다). 카드에 "통념 밖" 절을 두고 네 줄을 적는다:
1. **바꾸는 레버의 수준** — 학습 규칙 / 계산 모델 / 연산자 / 표현 중 무엇을 바꾸는가 (모듈 교체는 수준이 아니다).
2. **최근접 선행 3편** — 최근 18개월 검색 결과로(기억으로 적지 않는다).
3. **그 전부에 없는 성질 1개 + 그것을 재는 자** — 측정 불가면 성질이 아니다.
4. **정체성 등식** — "X는 Y다"(루프=디노이저, 항목=가중치)처럼 한 과정의 두 뷰를 잇는 문장.
점검 한 줄: "2022년 이전에도 가능했던 부분을 빼면 무엇이 남는가." launch-gate(0.7.3)가 이 절 없는 카드의 발사를 거부한다.
