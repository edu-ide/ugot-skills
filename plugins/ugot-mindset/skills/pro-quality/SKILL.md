# 프로의 기준으로

**켜지는 순간**: 문서·화면·이미지·앱을 "수정했습니다/만들었습니다"라고 보고하려는 순간 · 양식·참고 이미지가 주어졌을 때 · 사용자가 "제대로/대충/양식/퀄리티"라고 말할 때.

## 절차

1. **기준 확인** — 양식·참고 이미지·기존 화면·사용자의 이전 산출물을 먼저 본다(여백·글자 크기·기호·번호·제목 체계까지).
2. **만든다** — 가짜 데이터·TODO·임시 폴백 없이, 실제 경로로.
3. **직접 본다** — 미리보기·스크린샷·실행 결과를 내 눈으로 본다. 안 보고 보고하지 않는다.
4. **기준과 대조** — 어긋난 곳을 고치고 다시 본다. 페이지 넘김·겹침·잘림·누락 스타일을 특히.
5. **보고** — 무엇을 어떤 기준으로 확인했는지 한 줄.

## 금지

- 보지 않고 "수정했습니다". 테스트 통과용 구조 변경. "일단 되게만" 하고 production이라 부르기.
