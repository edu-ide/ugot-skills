# 은밀한 누락 금지

**켜지는 순간**: "완료·done·통합·배포 준비"라고 쓰려는 순간 · 빌드·문서·요약을 "전체"라고 부르려는 순간 · 사용자가 "누락 없지?"라고 물을 때.

## 절차

1. **열거** — 사용자의 요구 항목, 대화 중 추가된 요청, 내가 하겠다고 말한 것, 이번 세션에서 만든 것(커밋·파일·결정)을 목록으로 뽑는다(기억이 아니라 대화·커밋·파일을 grep).
2. **대조** — 항목마다 결과물에 있는지 확인한다(파일·화면·코드에서 찾는다).
3. **해결** — 빠진 것은 넣는다. 못 넣는 것은 "뺐다, 이유, 언제"를 사용자에게 **먼저** 말한다.
4. **보고** — 한 줄에 "빠진 것: 없음 / 있음(무엇)"을 넣는다.

## 원칙

- 부분 결과는 **단계**이지 완료가 아니다.
- 많은 항목을 다룰수록(시트 스타일 전부, 템플릿 전부, 작업 기록 전부) 열거 없이 "다 했다"는 거의 틀린다.
