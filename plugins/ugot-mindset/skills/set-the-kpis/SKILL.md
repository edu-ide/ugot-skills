# set-the-kpis (KPI 설정) — 이 기간의 성공 숫자를 먼저 정한다

**탄생 (2026-10-20 19:21 KST)**: 다섯 결정 스킬 뒤 사용자 "KPI set 스킬도 만들까". 이틀의 보고는 자(尺)는 많았지만(읽기·깊이·가린 바이트·단어 가림·손실) **"이 주의 성공 = 어느 숫자가 어디까지, 언제"**가 없었다 — 그래서 "성과가 뭐야", "언제 되냐"에 매번 새로 답을 지어냈고, "주 단위로 쓸 수 있는 모델" 같은 모호한 말이 나왔다. 실험 카드의 다섯 자는 실험의 KPI였지만, 노선(제품 경로)·기간(이번 주)·사람(사용자가 보는 것)의 KPI는 없었다.

## KPI 한 줄의 여섯 칸

`KPI-1 읽기 EM(SQuAD 1,000·48기사) — 자: eval_real_rc_benchmark · 현재 0.43(44M) · 목표 ≥ 0.77 · 10-27 · 담당 Claude · 짝 자: 학습-떼어 둔 격차 ≤ 0.10(외움 방지)`

| 칸 | 뜻 | 없으면 생기는 일 |
|---|---|---|
| 자 | 어떤 스크립트·데이터·표본으로 재나 | "성장 중"(눈먼 자) |
| 현재 | 지금 값(출처) | 올랐는지 모름 |
| 목표 | 통과선 | "잘 되고 있어?"에 답 못 함 |
| 날짜 | 언제까지 | "언제 되냐"에 답 못 함 |
| 담당 | 누가 | 아무도 안 봄 |
| 짝 자(굿하트) | 이 숫자만 올리면 생기는 속임수와 그걸 잡는 자 | 1B 외움(가린 바이트 0.845인데 읽기 0.21) |

## 규칙

- **2~5개.** 하나면 눈먼 자(2026-08 bpb 사고), 여섯 넘으면 아무도 안 본다.
- **END에서 거꾸로.** 먼저 "무엇을 위해"(제품·논제·고객 가치) 한 줄, 그다음 그것을 가장 잘 대변하는 숫자. 수단의 숫자(걸음 수·손실)는 KPI가 아니라 진행 지표.
- **공개 자 우선.** 공개 벤치·실사용·제3자 자 > 내부 자(REAL-WAY). 내부 자는 짝 자로만.
- **굿하트 점검 의무.** KPI마다 "이것만 올리는 가장 쉬운 속임수"를 한 줄 적고 그걸 잡는 짝 자를 둔다(읽기 EM ↔ 외움 격차, 속도 ↔ 품질, 제출 수 ↔ 합격률).
- **날짜는 시계로**(honest-eta), **목표는 선례·기준선으로**(DistilBERT 0.77, 기준 제품) 정한다 — 희망으로 정하지 않는다.
- **보고 = KPI 표 갱신.** 상태 보고 3줄은 KPI의 현재/목표/날짜로 쓴다. 숫자가 안 움직이면 KPI를 바꾸지 말고 **방향을 의심**(question-the-task-first). KPI 변경은 이유와 함께 기록(카드 §6).

## 층위 (한 작업에 셋이 겹칠 수 있다)

| 층 | 예 | 주기 |
|---|---|---|
| 노선(제품 경로) | 읽기 EM ≥ 0.77, GSM8K ≥ x, HumanEval ≥ y, 응답 지연 ≤ z초 | 주간 |
| 실험(카드) | 카드 §3 다섯 자 + 통과선 | 런마다 |
| 사람(사용자가 보는 것) | "써 볼 수 있는 데모가 있나(예/아니오)", 주간 보고 1장 | 주간 |

## 절차 (3분)

1. END 한 줄. 2. 층 고르기. 3. KPI 2~5개를 여섯 칸으로. 4. 굿하트 한 줄씩. 5. `KPI:` 블록을 카드 §0/답/주간 보고에. 6. 보고마다 갱신.

## 오늘의 적용 (본보기, 2026-10-20 — 제품 경로 1주차)

- END: 몇 주 안에 읽고·말하고·공개 벤치 숫자가 있는 모델.
- KPI-1 읽기 EM(SQuAD 1,000·48기사): 현재 0.43(44M) → 목표 ≥ 0.77 · 10-27 · 짝 자: 학습-떼어 둔 격차 ≤ 0.10.
- KPI-2 수학 GSM8K(공개 500문항 EM): 현재 미측정(바탕 모델 카드값으로 시작) → 목표 바탕 대비 +5p · 10-27 · 짝 자: 검증기 없는 답 비율.
- KPI-3 코드 HumanEval(pass@1): 현재 미측정 → 목표 바탕 대비 −0p(우리 층이 깎지 않음) · 10-27.
- KPI-4 써 볼 수 있는 데모(채팅으로 읽기+대화, 예/아니오): 현재 아니오 → 목표 예 · 10-24.
- KPI-5 비용: 4090 1장·실험당 ≤ 6h · 상시.

## 관계

- `multi-ruler`: 자의 다양성과 재채점의 정본 — KPI는 그 자 중 **이 기간의 목표가 걸린 것**을 고른 것.
- `signal-early-verdict`·pre-register: 실험 층 KPI의 사전 등록 형식.
- `honest-eta`: 날짜 칸. `question-the-task-first`·`set-the-lens`: KPI가 안 움직일 때 바꾸는 것은 KPI가 아니라 방향.
- `five-w-one-h`: KPI는 "무엇을·언제"의 숫자판; 육하원칙이 나머지(누가·어디서·어떻게·왜)를 채운다.
