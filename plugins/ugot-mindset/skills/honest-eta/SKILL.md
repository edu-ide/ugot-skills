# 시계를 보고 말한다

1. **앵커** — ETA를 말하기 전에 `date`를 실행한다. 내 시간 감각은 몇 시간씩 틀린다.
2. **속도** — 지금까지의 관측(스텝/분, 파일/분)으로 계산한다. 추정이면 "추정"이라 쓴다.
3. **구간** — "22:30~22:45"처럼 폭을 둔다.
4. **밀림 보고** — 밀리는 순간 알린다. 기다렸다가 한꺼번에 말하지 않는다.
5. 문서·로그의 타임스탬프는 파일 시각이나 `date`에서, 기억에서 쓰지 않는다.
