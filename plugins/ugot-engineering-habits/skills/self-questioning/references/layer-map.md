# AI 아키텍처의 모든 수준을 살피는 질문 지도

범용 자기질문을 AI 모델의 구조·기억·학습 메커니즘 설계에 적용할 때 읽는다. 일반 문제 해결에는 이 문서의 모델 전용 절차를 가져오지 않는다.

현재 후보의 실제 경로와 아래 범주를 대응시킨다. 이는 최소 탐색 지도다. 후보에 다른 층이나 새로운 경계가 있으면 추가한다. 각 범주에서 문제 징후를 훑고, 판단을 막는 곳을 깊게 조사한다. 모든 연산을 매번 재구현하는 절차로 쓰지 않는다.

| 층·경계 | 반복해서 물을 핵심 질문 |
| --- | --- |
| 목표·과제·사용 환경 | 목표가 특정 대리 과제로 축소됐는가? 실제 생성·추론·시각·음성·도구 사용 가운데 무엇을 검증하고 무엇이 남는가? |
| 입력·모달리티·토큰화 | 원문, 이미지, 음성, 출처, 관측 시각, 유효 시점 중 필요한 정보가 모델 입력 전에 사라지는가? 인코딩·분할·압축이 구별해야 할 사례를 합치는가? |
| 임베딩·위치·주소·표현 | 의미·순서·출처·신뢰·버전을 구별할 수 있는가? 주소와 사실의 신뢰성을 혼동하는가? 좌표 변경이나 정규화가 필요한 크기 정보를 제거하는가? |
| Q/K/V·선택·읽기 | 주소 조회와 관계 추론이 같은 연산에 부적절하게 묶였는가? softmax 경쟁, 중복·길이, 압축·희소 선택이 근거를 숨기는가? key/value가 다음 세션·수정·모델 교체에서 어떤 의미를 유지하는가? |
| MLP·지식·내부 연산 | 공통 계산과 개별 사실이 어떻게 얽히는가? 입력에 따른 변환, 새로운 관계, 국소 수정에 필요한 표현력이 있는가? 활성함수·행렬 분해·전문가 선택을 유지하는 근거는 무엇인가? |
| 상태·residual·정규화·반복 | 보존·덮어쓰기·간섭·망각이 어떤 법칙을 따르는가? 깊이·시간에 걸친 정보와 gradient가 사라지거나 폭주하는가? 가역성·안정성 증명은 실제 무엇만 보장하는가? |
| 기록·수정·삭제·통합 | 모델이 무엇을 기록할지 배우는가? 최신 값과 과거 값, 원본과 파생 기록의 의존성을 구별하는가? 삭제된 사실이 요약·대화 이력·가중치를 통해 다시 들어오는가? |
| 영속화·재시작·모델 갱신 | 저장한 데이터와 해석할 모델·토크나이저·계산 조건이 함께 추적되는가? cache 복구와 기억의 의미 보존을 혼동하는가? 재컴파일·변환 비용과 실패 조건은 무엇인가? |
| 추론·행동·출력 | 내부 기억과 판단이 실제 출력에 인과적으로 기여하는가? 반복 깊이·중단·계획·도구 관찰 이후 상태 갱신이 일관되는가? tied head 등 출력 제약이 필요한 능력을 막는가? |
| 데이터·손실·학습 신호 | 목표 행동을 가르치는 정보가 있는가? 기록의 미래 효용과 현재 답의 손실이 연결되는가? 이산 선택의 신용 할당, 에피소드 격리, 데이터 누출은 처리됐는가? |
| 초기화·optimizer·학습 주기 | 구조와 optimizer의 상호작용을 구조 자체의 한계로 오해하는가? 짧고 긴 학습, 분포 변화, 온라인 갱신의 차이를 설명할 수 있는가? |
| 숫자 표현·기본 연산·커널·하드웨어 | 정밀도·양자화·누산·미분 방식·행렬 연산·메모리 배치·장치 제약이 정확성·학습·비용을 막는가? 추상 연산과 실제 커널의 차이인가? 더 낮은 수준의 새 표현·연산·실행 방식이 필요한가? |
| 평가·비교·계측 | 필요한 능력을 실제로 재는가? 기준선이 부당하게 약한가? 전체 비용·실패 조건·미완료 실행·기존 능력 회귀가 빠졌는가? |

인접 층의 계약도 검사한다. 저장소에 출처 필드가 있어도 encoder가 내용 토큰만 읽으면 출처를 이용한 판단은 배울 수 없다. 잘 정의된 삭제 연산도 읽기 cache가 예전 snapshot을 쓰면 출력에 반영되지 않는다. 빠른 커널도 수치 오차 때문에 학습을 망치면 전체 효율 개선이 아니다. 이런 사례는 조사 질문이며, 현재 후보에 같은 결함이 있다는 결론은 실제 근거로 확인한다.

하드웨어까지 질문 범위에 포함하되 장비 교체·구매나 서비스 중단으로 작업 권한을 넓히지 않는다. 현재 제약 안의 개선과 별도 자원이 필요한 가설을 구별한다.

## 설계에서 전체 후보 검증까지

기존 연구 지침과 최신 코드·결과·철회된 진단을 먼저 확인한다. 핵심 후보를 바꿀 때는 관련 최신 논문 원문·공식 구현·후속 교정을 조사하고 기존 실험과 대조한다. 이미 확인한 자료는 재사용하되 확인한 범위를 적는다. 기존 원리, 새로운 결합·연산, 아직 검증하지 않은 가설을 구별한다.

선택한 필수 변경을 일관된 상태·정보 흐름·학습 신호·저장 및 복원 계약으로 합성한다. 알려진 필수 조건을 빠뜨린 후보를 완성했다고 하지 않는다. 모든 층을 동시에 교체할 필요는 없지만, 보류한 결함과 그로 인해 할 수 없는 주장을 남긴다.

수학·인과성·누출·복원·gradient·수치 안정성의 필수 검사 뒤, 선택한 범위를 완성한 전체 후보를 강한 기준선과 비교한다. 부품마다 성능 관문을 통과시키는 연쇄로 전체 비교를 미루지 않는다. 기여 분석은 전체 비교와 연결한다.

기준선에도 적절한 학습 조건을 제공하고 정보·데이터·계산·저장·벽시계 비용과 회귀를 기록한다. 짧은 구간과 긴 구간, 같은 레시피와 각 후보에 적합한 레시피의 질문을 구별한다. 구조 검사·합성 성공·초기 우세로 실제 범용 성능이나 모든 조건의 우세를 선언하지 않는다.
